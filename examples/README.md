# Examples

Runnable snippets that show off the Durbl SDK.

| File | What it shows |
|---|---|
| [`quickstart.py`](./quickstart.py) | Write a memory, recall it back |
| [`agent_memory.py`](./agent_memory.py) | Persistent memory for an LLM agent across sessions |
| [`async_example.py`](./async_example.py) | Async / `await` usage with the same API |

## Running

```bash
pip install durbl-sdk
export DURBL_API_KEY="drbl_..."   # from https://console.durbl.dev
python examples/quickstart.py
```

Get an API key at **[console.durbl.dev](https://console.durbl.dev)**.
