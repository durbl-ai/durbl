# Security Policy

## Reporting a vulnerability

If you find a security issue in the Durbl SDK or in the Durbl service, **please do not open a public GitHub issue**.

Email **security@durbl.dev** with:
- A clear description of the issue
- Steps to reproduce (if possible)
- Your name / handle if you'd like to be credited

We aim to respond within **48 hours** and to publish a fix or mitigation as quickly as the severity demands.

## Scope

This repository contains only the public Python client. Findings related to the engine, API, billing, or hosted service should still be sent to the same address — they will be routed to the right team.

## Out of scope

- Issues that require physical access to a victim's machine
- Self-XSS or social engineering against the reporter
- Findings against forks or unofficial mirrors of this repo

Thanks for helping keep Durbl users safe.
